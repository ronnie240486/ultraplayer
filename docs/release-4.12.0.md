# UltraPlayer 4.12.0 — controles e mini player mais altos

A versão 4.12.0 ajusta a escala vertical do modo **TV Box** sem aumentar as larguras. Os botões principais, os botões de Configurações, opções de tema, botões de reprodução, seletor de temporadas e ações de detalhes recebem mais altura para facilitar o uso com controle remoto e visualização à distância. A largura dos elementos permanece preservada.

O mini player também foi aumentado apenas no eixo vertical. No modo Celular, a altura padrão passa para 230 dp; na TV Box, a proporção vertical do quadro é maior. Quando o WebView mede o espaço do player, o Android acrescenta altura vertical adicional diferente por modo, mantendo a largura medida e as margens horizontais. A reprodução continua horizontal e usa o mesmo player nativo.

A área de vídeo ao vivo recebeu altura maior no layout dos dois modos, também sem alterar a divisão horizontal das colunas. A alteração não muda o comportamento de categorias, rádios, filmes ou séries.
