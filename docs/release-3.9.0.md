# UltraPlayer 3.9.0 — canais compactos e EPG ampliado

A coluna de canais foi compactada para mostrar somente a informação necessária: cards de 50px de altura, logos de 32px, nomes em fonte menor e numeração reduzida. A intenção é liberar área visual para a programação.

A coluna direita foi ampliada para 55% da tela horizontal. O mini player ocupa a parte superior com altura proporcional menor, e o EPG ocupa o restante do painel com rolagem independente.

O APK foi compilado com package `com.ultraplayer.app`, nome `UltraPlayer`, versionName `3.9.0`, versionCode `30` e build debug.
