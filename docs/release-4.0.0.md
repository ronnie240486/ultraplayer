# UltraPlayer 4.0.0 — tela de canais em altura total

A faixa inferior que cobria a tela foi removida no layout horizontal. A tela de Canais, o `sidebar-content` e o grid principal usam toda a altura disponível do WebView.

A coluna de categorias foi ampliada de 15% para 17%, permitindo que grupos como HBO, Telecine e Esportes tenham mais espaço. A coluna central continua compacta, com logos de 32px, cards de 50px e nomes reduzidos. A coluna direita usa 55% da tela; o player fica no topo e o EPG ocupa o quadro inferior com rolagem independente.

O splash HTML também mostra o logo oficial `assets/branding/ultraplayer_launcher.png` antes do carregamento, acompanhado do nome UltraPlayer e do indicador de progresso.

O APK foi compilado com package `com.ultraplayer.app`, nome `UltraPlayer`, versionName `4.0.0`, versionCode `31` e build debug.
