# UltraPlayer 2.6.0 — confirmação de alarme do EPG

Ao tocar no sino de qualquer programação futura, o UltraPlayer salva o alarme e exibe imediatamente uma confirmação visual com a mensagem: **Te avisaremos quando sua programação começar.** O sino muda para o estado ativo e permanece destacado enquanto o alerta estiver salvo.

Ao tocar novamente no mesmo sino, o alerta é removido e o aplicativo informa **Alerta removido.** Programas que já começaram não recebem alarme e exibem a mensagem correspondente.

O suporte a múltiplos sinos permanece independente: cada programação possui uma chave própria baseada em horário, título e canal. Alarmes que chegam simultaneamente entram em fila de modais, evitando que um aviso seja perdido.

O APK foi compilado com package `com.ultraplayer.app`, nome `UltraPlayer`, versionName `2.6.0`, versionCode `17` e build debug.
