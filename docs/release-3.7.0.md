# UltraPlayer 3.7.0 — cards de canais compactos

A coluna central de canais foi reduzida para liberar mais espaço ao player e ao EPG. Os cards de Band, Globo e demais canais agora têm altura de 78px, logo de 54px, padding menor e tipografia reduzida.

A coluna direita foi ampliada para 44% da área disponível. O player permanece no topo e o EPG ocupa a parte inferior, mantendo rolagem própria. A coluna esquerda de categorias não foi alterada nesta versão.

O APK foi compilado com package `com.ultraplayer.app`, nome `UltraPlayer`, versionName `3.7.0`, versionCode `28` e build debug.
