# UltraPlayer 4.1.0 — player ampliado e EPG completo

O layout horizontal foi ajustado para aproveitar toda a altura da tela. O mini player ocupa uma área maior no topo da coluna direita, enquanto o EPG ocupa o espaço restante abaixo, com rolagem independente até o último programa.

A tipografia do EPG foi reduzida sem diminuir o painel: horários usam fonte compacta, títulos têm 14px e cada item ocupa menos altura. Os canais continuam com cards compactos para não disputar espaço com o painel direito.

O mini player agora guarda o payload do canal selecionado. Ao tocar na imagem do mini player, o aplicativo abre a `PlayerActivity` em tela cheia com o mesmo canal; o botão de fechar continua apenas fechando o mini player.

O APK foi compilado com package `com.ultraplayer.app`, nome `UltraPlayer`, versionName `4.1.0`, versionCode `32` e build debug.
