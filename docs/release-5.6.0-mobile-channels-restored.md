# Fusion 5.6.0 — Canais restaurados no Celular

A proteção de recuperação de catálogo vazio foi restringida ao modo TV Box. O Celular volta a seguir o caminho anterior de carregamento da tela Live, que já funcionava, sem forçar uma segunda consulta integral nem cair no fallback de erro.

As otimizações de EPG adiado, logos em lotes, rolagem manual e troca protegida de categorias continuam disponíveis para a TV Box.

Validação: `node --check` aprovado para `zlocal.js`, `tv.js` e `category_browser.js`; build release com R8 aprovado.
