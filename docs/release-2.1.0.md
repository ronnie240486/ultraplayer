# UltraPlayer 2.1.0 — logo oficial, temas ampliados e avatares infantis

A versão 2.1.0 usa o logo fornecido pelo usuário como recurso de launcher do Android. O manifest aponta para `@drawable/ultraplayer_launcher`, gerado a partir da imagem enviada e empacotado em 512×512 para aparecer como ícone do aplicativo instalado.

O seletor **Cores do aplicativo** foi ampliado para doze temas: Verde esmeralda, Branco, Preto, Amarelo, Verde-musgo, Azul oceano, Lilás, Vermelho, Rosa, Cinza grafite, Turquesa e Dourado. As opções alteram acento, fundo, painéis, textos, bordas e estados de foco e ficam salvas no aparelho.

O editor de perfil agora alterna entre a coleção padrão de avatares e uma coleção infantil dedicada. A coleção infantil contém cinco personagens ilustrados: explorador espacial, fada, dragão amigável, robô e pirata. Ao ligar o Perfil infantil, o avatar atual e a grade de seleção mudam para essa coleção; ao desligar, retornam à coleção normal.

O Perfil infantil continua removendo conteúdos adultos por categoria e por nome no catálogo Xtream e na M3U. A tela de edição de perfil segue fixa, sem escala automática e sem deslocamento lateral.

O APK foi compilado com package `com.ultraplayer.app`, nome `UltraPlayer`, versionName `2.1.0`, versionCode `12` e `minSdk 21`. A build é debug para testes.
