# UltraPlayer 3.0.0 — layout TV Box corrigido

O modo TV Box agora reserva a tela para uma estrutura fixa: categorias compactas à esquerda, canais no centro e uma coluna direita dedicada ao vídeo e ao EPG. A largura da coluna de categorias foi reduzida para que não ocupe o espaço do player.

O mini player nativo foi reduzido para ocupar apenas a área direita do vídeo. O EPG fica em um painel abaixo dessa área, com altura própria e rolagem interna, permanecendo visível mesmo quando há muitos programas.

O modo Celular continua em coluna vertical, sem receber a grade fixa de TV Box. A escolha entre Celular e TV / Caixa permanece disponível na primeira abertura e em Configurações → Tela do app.

O APK foi compilado com package `com.ultraplayer.app`, nome `UltraPlayer`, versionName `3.0.0`, versionCode `21` e build debug.
